상상배달 지원

야식 참는 가짜 배달앱 · 아이폰

궁금한 점이나 오류는 hello@irukabloom.com으로 보내 주세요. 아이폰 기종, iOS 버전, 어떤 화면에서 생겼는지 적어 주시면 더 빨리 도와드릴 수 있어요.

자주 묻는 질문

진짜로 음식이 오거나 돈이 나가나요?

아니요. 상상배달의 주문과 결제는 모두 흉내예요. 결제 화면에도 「실제 결제 아님」이라고 적혀 있고, 카드 번호를 넣는 칸도 없어요. 가게와 메뉴도 전부 지어낸 것이에요.

참은 돈은 어떻게 계산되나요?

상상으로 주문한 금액이 그대로 「참은 돈」으로 쌓여요. 하루에 인정되는 금액은 최대 5만 원이에요. 칼로리는 메뉴마다 대략의 값이에요.

평생 이용권은 무엇이 달라지나요?

한 번만 사면 되는 구매예요. 전체 기록과 월별 그래프, 직접 입력 무제한, 중간 위젯, 잠금화면·다이내믹 아일랜드 배달 표시, 특별 옷장, 공유 카드에서 앱 이름 숨기기가 열려요. 잠금화면 배달 표시는 처음 3번은 무료로 써 볼 수 있어요.

휴대폰을 바꿨는데 평생 이용권이 사라졌어요.

같은 Apple ID로 로그인한 뒤 설정 화면이나 평생 이용권 화면의 「구매 복원」을 눌러 주세요. 다시 결제되지 않아요.

기록은 어디에 저장되나요? 폰을 바꾸면 옮겨지나요?

기록은 내 아이폰과 내 iCloud 계정에만 저장돼요. 새 아이폰에서 같은 Apple ID로 iCloud가 켜져 있으면 기록이 자동으로 돌아와요. 아이폰 설정 → 내 이름 → iCloud에서 상상배달이 켜져 있는지 확인해 주세요.

위치 권한은 왜 필요한가요?

지도에서 「우리집」 주소를 정할 때만 현재 위치를 써요. 위치를 허용하지 않아도 주소를 직접 골라 쓸 수 있고, 위치 정보는 개발자에게 보내지지 않아요.

잠금화면에 배달 표시가 안 떠요.

아이폰 설정 → 상상배달 → 「실시간 현황」이 켜져 있는지 확인해 주세요. 무료로 써 볼 수 있는 3번을 다 쓰셨다면, 그다음부터는 평생 이용권이 있어야 보여요.

기록을 모두 지우고 싶어요.

앱을 지우면 아이폰에 있는 기록이 지워져요. iCloud에 있는 백업까지 지우려면 아이폰 설정 → 내 이름 → iCloud → 계정 저장 공간 관리에서 상상배달 데이터를 삭제해 주세요.
